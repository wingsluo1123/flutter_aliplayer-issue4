# flutter_aliplayer 黑盒测试用例

## 测试范围概述

flutter_aliplayer 是阿里云播放器 Flutter 插件，鸿蒙化适配后以 HarmonyOS AVPlayer 为播放内核，XComponent 为视频渲染面，AVImageGenerator 用于截图与帧提取。本测试用例覆盖播放器实例与生命周期、视频源设置、播放控制、视频渲染面、播放配置、轨道管理、字幕、截图与缩略图、渲染模式、播放属性、事件回调、列表播放器、直播时移、视频下载、媒体预加载、全局设置、全局播放器设置等 17 个功能模块。

- **测试范围说明**：覆盖所有公开功能，从用户视角进行黑盒测试
- **测试级别说明**：
  - L0 = 核心功能的正常流程（≤30%）
  - L1 = 其他正常流程（≤40%）
  - L2 = 异常流程/边界值（剩余比例）
  - **注意**：L3 级别已废弃，不再使用

**生成级别**：L0（仅生成 L0 级别测试用例，共 49 个）
